# Security policy

Report provenance bypasses, unexpected plugin repository writes, or credential exposure with
this repository's GitHub **Report a vulnerability** action. Do not put tokens or
private service URLs in public issues.

Plugin repository allowlist and workflow changes control which software can be distributed
to users. A signature proves the approved workflow produced an artifact; it does
not replace source review. Existing releases stay immutable when a fix is needed.

Maintainers give a first answer within 14 days of a report. A fix has no promised date;
how long it takes depends on the case. This is the answer time of the JellySin
organisation's security policy: https://github.com/jellysin/.github/blob/main/SECURITY.md
